Service & Process Discovery Rules

Discovery rules pin services and processes for monitoring — or monitoring plus the Application Map — on the devices they select: those that match today, and those discovered later. Rules marked Auto were created from Monitor/Map checkboxes on individual assets and consolidate automatically as more assets pin the same item. Removing an item or disabling a rule stops future auto-pinning; it doesn't unpin what's already there.

Polaris Agent

Build the agent binaries that operators install on remote hosts via Install Agent on the asset details modal. Binaries are stamped with the version from agent/VERSION and served at /api/v1/agents/binary/<filename> to the install scripts.

SSH Deployment

Deploying the agent over SSH with a key takes a reusable administrator password off the wire. Polaris generates one keypair, keeps the private half sealed, and produces the onboarding script for each platform — getting right the details that fail silently when hand-rolled: on Windows the administrators_authorized_keys path and its ACL, on Linux the ~/.ssh ownership, SELinux context, and the passwordless-sudo drop-in the agent installer requires. Deploy with Intune, GPO, Configuration Manager, Arc, Ansible, an RMM tool, or by hand.
