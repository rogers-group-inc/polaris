Path Monitor

Checks the Polaris Agent runs from the hosts you choose: an HTTP / HTTPS request, a TCP connect or a ping, with a traceroute of the path. Results appear on each host's Paths tab. To be alerted, create an automation on the Path metrics (latency, failure rate, HTTP status…) — a check has no threshold of its own, and never changes the host's own Up / Down status.
