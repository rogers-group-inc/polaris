Read-only by default; a "Customize Page" button (top-right) enters EDIT MODE ("Add Widgets" + "Done Editing"). The dashboard is an ordered list of COLUMNS (each a 12-grid width 3/4/6/12) holding a vertical stack of widgets (height step 1–3 → 280/576/872px). In edit mode: "Add Widgets" opens the full picker (translucent overlay with the dashboard dimmed behind it, a Group-By category list, search, name sort, and a ★ favorite toggle per widget — favorites in localStorage via favorites.js); drag a widget (from the picker or an existing one) → a green "+" insertion placeholder marks the slot and a trailing "+ New block" target accepts drops into a fresh column; the dragged widget lifts with a shadow. newly-added widgets default to **My regions** (an unrestricted caller with no effective regions still sees everything), and the unauthenticated /dash wallboard hides **My regions** — no viewer identity to resolve it against — leaving All / Selected regions — and every NOC widget except the Status Map carries an **Asset types** toggle grid — the built-ins (the eight historical + `hypervisor` + `kubernetes_cluster`) painted immediately, then repainted from `/dashboard/filter-options` with every operator-added type PRESENT in the fleet, registry-labelled, default all on; both rendered by the shared `PolarisWidgets.renderNocFilterConfig`, threaded to the server as `?hideAssetTypes=&regionTags=` (the grid stores the switched-OFF names in `config.assetTypesOff`, which is what lets a custom type be hidden at all) so the payload is memoized per filter; every severity-bearing widget (Down Assets, Down Interfaces, Storage Forecast, the six top-N widgets, Active Alerts) additionally carries a **Minimum severity** select — All rows (default) / Notice / Informational / Warning / Serious and up / Critical only, the same ladder the ⤓ CSV export tiers use — that narrows the widget to rows whose device carries an active alert at or above that severity, filtered client-side before the row limit / header count / export (any tier past "All rows" therefore hides un-alerted rows, which the popover hint states); when the asset-type filter narrows, the header title names it the shorter way round — the types shown, e.g. "Highest Avg CPU (Server, Switch)", or the exclusions when fewer are off than on, e.g. "Down Assets (excl. Printer, Network Camera)"), and remove ×.
