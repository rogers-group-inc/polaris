# SearchHints

The panel of example queries shown under an empty search bar.

Markup is `.search-hint-section` with a `.search-hint-section-label`, a two-column
`.search-hint-grid` of `.search-hint-chip` buttons, and an optional `.search-hint-foot`.
Each chip holds `.search-hint-keys` — one or more `.search-hint-key` examples, joined by
`.search-hint-or` — and a `.search-hint-label` naming the field.

- The examples and labels in this preview are illustrative; the app supplies its own.
- Keys are set in a monospace face; use real-looking identifiers, not prose.
