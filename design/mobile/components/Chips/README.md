# Chips

Filter chips in a horizontally scrolling row.

Place `.chip` buttons inside `.chip-row`, which scrolls sideways without a scrollbar. The
consumer provides each label and toggles `.selected`, which fills the chip with
`md-secondary-container` and makes room for a leading 18px check glyph.

- Chips filter a list in place; they are not navigation.
- Keep labels to one or two words so the row stays scannable.
