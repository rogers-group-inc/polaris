# EmptyState

The message shown when a list or search has nothing to show.

Markup is `.empty-state > .icon + .ttl + .desc`: a 64px glyph well, a one-line title and
a short description capped at 280px. The consumer provides the glyph, the title and the
description.

- Say what is empty and what to do about it; don't apologise.
- Use it in place of the list, not above an empty one.
