Topology views

A Device Map site has a default view and may have more, shared by everyone who can open the map (business rule 147). Each view has ONE mode — Layer 2, Topology or Room (a room's racks and junction boxes side by side, rule 156) — and the device types it shows. The header names the view and its mode; the details pane starts with the Device types toggles.
