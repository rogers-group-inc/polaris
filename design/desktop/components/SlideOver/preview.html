Slide-over

Entity detail views: an asset, a network, a block. The panel stays open while the user works the page underneath, so it is deliberately not aria-modal and has no hard focus trap. The header holds the name, a meta line and the tab strip, and stays still. Only the body scrolls. Each tab is a stack of sections, and each section says where its data came from and how fresh it is.

  • One z-index for every slide-over; DOM order stacks them, a new one is raised on open, and Escape closes only the topmost.
  • Tabs are in a fixed order and appear only when the device has that data (no SD-WAN tab on a switch).
  • Every section heading names its polling method, cadence and tier, plus an "updated … ago" stamp that turns amber after one missed cadence.
  • A snapshot section (Wireless, MAC table, ARP table) also gets a Poll button at the far right, shown only to roles that can poll.
  • The stale banner sits inside the section, before its chart or table, on the empty state as well.
  • .slideover-body has zero padding: wrap its content in one padded div.
