Ownerless

One tree for both menus (public/js/saved-tree.js, business rule 140). A folder row is .sft-folder: a .sft-toggle (chevron, folder icon, name, .sft-count, Public badge, owner) and a .sft-more ⋯ that opens the ordinary row menu. Children indent 20px per level with an inline padding-left. While dragging, the row dims (.sft-dragging) and the folder or section heading it would land in takes a dashed accent outline (.sft-drop). The owner label reads Role · …, Region · …, a username, or was … when ownerless; it is omitted on what is simply yours. Rename edits in place (.sft-rename).

Change owner

You will no longer own this folder. Only members of the NOC Operators role will be able to rename, move, publish, delete or hand it on.

You can’t undo this yourself; the new owner would have to give it back.

.sfo-kind is the owner grid (a radio column, a picker column); .sfo-warn is the warning callout Change owner and Make private to me both use — a warning-tinted box with its icon, never a toast, because the reader must see it BEFORE confirming. The confirm button is .btn-warning, not danger: nothing is deleted.
